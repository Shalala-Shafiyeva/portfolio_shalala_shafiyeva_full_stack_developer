# Портфолио Shalala Shafiyeva

React + Vite + Tailwind CSS. Три языка (AZ / EN / RU), светлая и тёмная тема.

## Запуск

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # сборка в папку dist
npm run preview  # посмотреть собранную версию
```

Нужен Node.js 18 или новее.

## Где что менять

Весь контент лежит в `src/data/`, компоненты трогать не нужно.

| Файл | Что внутри |
|------|-----------|
| `src/data/profile.js` | имя, почта, телефон, GitHub, **LinkedIn**, путь к фото |
| `src/data/projects.js` | проекты: описание на 3 языках, ссылки, скриншоты, вкладка Backend |
| `src/data/experience.js` | опыт работы |
| `src/data/skills.js` | навыки |
| `src/data/education.js` | образование и языки |
| `src/i18n/translations.js` | все тексты интерфейса на трёх языках |

### Добавить проект
Скопируйте объект в `PROJECTS` в `src/data/projects.js` и поменяйте поля: название, описание на трёх
языках, ссылку `demo` на живой сайт и (по желанию) `code` со ссылкой на GitHub.
Сайт показывается прямо в портфолио во фрейме, с переключателем «компьютер / телефон».
Если сайт не отображается во фрейме (хост запрещает встраивание), останется кнопка «Открыть сайт».
Для «обложки» до запуска предпросмотра положите картинку в `public/assets/` и укажите `shots: ['assets/my.png']`.

> Описание проекта NextCore в `projects.js` временное. Замените его на реальное.

### Фото
Положите `public/assets/photo.jpg`. Пока файла нет, фото не показывается.

### Цвета и тема
Цвета светлой и тёмной темы заданы переменными в `src/index.css` (`:root` и `.dark`).
Переключатель темы запоминает выбор и при первом заходе учитывает системную тему.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него весь проект (включая папку `.github`).
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. После каждого `git push` в ветку `main` сайт собирается и публикуется автоматически
   (workflow `.github/workflows/deploy.yml`).

Ссылки на конкретный язык для резюме и откликов:
`https://USERNAME.github.io/REPO/?lang=az`, `?lang=en`, `?lang=ru`.
